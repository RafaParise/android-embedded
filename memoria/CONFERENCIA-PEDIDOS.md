# Conferência de pedidos

No repositório de trabalho, este arquivo é a lista de conferência de cada pedido do dono do projeto
(o que foi pedido, o veredito e a prova). Ela tem detalhes pessoais e fica só na cópia privada.

O formato, para quem quiser usar no próprio projeto:

| Pedido (resumo fiel) | Veredito | Evidência |
|---|---|---|
| O que a pessoa pediu, com as palavras dela | CUMPRIDO · PARCIAL · DEPENDE DELA · PENDENTE · RECUSADO (com motivo) | arquivo, commit ou medida que prova |
